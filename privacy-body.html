1. Общие сведения

1.1. Настоящая Политика конфиденциальности (далее — «Политика») описывает, какие данные связаны с использованием Life Visuals (далее — «Продукт») и как разработчик Life Visuals (далее — «Разработчик») относится к обработке информации.

1.2. Мы придерживаемся принципа минимального сбора данных: Продукт спроектирован так, чтобы не собирать персональные данные Пользователя на стороне Разработчика.

1.3. Используя Продукт и этот сайт, Пользователь подтверждает, что ознакомился с Политикой. Если Пользователь не согласен — следует прекратить использование Продукта и покинуть сайт.

1.4. Политика применяется к клиентскому Продукту Life Visuals, связанным материалам и данной веб-странице условий.

2. Какие данные обрабатываются

2.1. Локальные данные (хранятся только на устройстве Пользователя и по умолчанию не передаются Разработчику):

  • настройки Продукта (JSON-конфигурация, темы, положение элементов HUD, выбранные модули интерфейса);
  • состояние интерфейса, кэш ресурсов и временные файлы, создаваемые игрой или лаунчером;
  • логи Minecraft / Fabric, которые Пользователь может создавать локально при сбоях.

2.2. Данные, которые мы НЕ собираем и НЕ получаем через Продукт:

  • персональные данные (имя, фамилия, email, телефон, адрес, паспортные данные и т.д.);
  • IP-адрес, MAC-адрес, идентификаторы устройств, отпечатки браузера — в рамках работы самого клиента Life Visuals;
  • историю игры, чат, инвентарь, координаты, статистику, список друзей;
  • токены, пароли, session ID, cookies, данные аккаунтов Microsoft / Mojang / Xbox;
  • биометрию, платёжные данные, геолокацию в реальном времени;
  • любые данные, позволяющие идентифицировать Пользователя как личность на стороне Разработчика.

2.3. Данные на стороне игровых серверов (например Life SMP) обрабатываются администрацией соответствующего сервера по своим правилам и не контролируются настоящей Политикой в полном объёме. Обращайтесь к правилам сервера отдельно.

2.4. Данные сайта: при открытии этой страницы на GitHub Pages стандартные технические логи могут обрабатываться инфраструктурой GitHub / CDN (IP, User-Agent, время запроса) в соответствии с политикой GitHub. Разработчик Life Visuals не управляет этими логами напрямую.

3. Цели обработки

3.1. Локальные настройки используются исключительно для работы интерфейса Продукта на устройстве Пользователя.

3.2. Разработчик не использует данные Пользователя для рекламы, профилирования, продажи баз данных или передачи маркетологам.

3.3. Если Пользователь добровольно пишет в Discord или иные каналы поддержки, он сам передаёт туда текст сообщения и связанные метаданные платформы. Такие обращения обрабатываются только для ответа на запрос.

4. Передача данных и сторонние сервисы

4.1. Разработчик не продаёт, не сдаёт в аренду и не передаёт персональные данные Пользователя третьим лицам для их маркетинга.

4.2. Продукт не содержит встроенной аналитики, трекеров рекламы, скрытых модулей телеметрии и не отправляет игровой прогресс Разработчику.

4.3. Разработчик не имеет удалённого доступа к файлам, настройкам или данным на устройстве Пользователя.

4.4. Сторонние сервисы (Minecraft, Microsoft, хостинг сервера, GitHub Pages, Discord) действуют по собственным политикам конфиденциальности. Пользователь использует их на свой риск и по их правилам.

4.5. Виджет статуса сервера на этой странице может обращаться к публичным API проверки серверов (например mcsrvstat.us) для отображения online / players / version. Эти запросы не передают Разработчику личные данные Пользователя сайта сверх обычного сетевого обмена браузера с API.

5. Хранение и безопасность

5.1. Настройки и данные Продукта хранятся локально на устройстве Пользователя. Срок хранения определяет сам Пользователь (удаление мода / конфигов / игры).

5.2. Ответственность за сохранность устройства, учётных записей Microsoft / Mojang, антивирусную защиту и резервное копирование несёт Пользователь.

5.3. Разработчик рекомендует не устанавливать Продукт из неизвестных источников и проверять контрольные суммы / источник загрузки, если они публикуются официально.

5.4. Ни один способ передачи данных через интернет не является абсолютно безопасным. Пользователь осознаёт риски использования сети и игровых сервисов.

6. Права Пользователя

6.1. Поскольку Разработчик по умолчанию не хранит персональные данные Пользователя на своих серверах, запросы на «удаление аккаунта у Разработчика» обычно не применимы — достаточно удалить Продукт и локальные конфиги.

6.2. Пользователь может в любой момент:

  • удалить Продукт и папки конфигурации;
  • очистить кэш лаунчера и игры;
  • прекратить использование сайта и серверов.

6.3. По вопросам Политики можно связаться с командой через Discord-контакты, указанные в разделе «Команда».

7.1. Продукт не предназначен для целенаправленного сбора данных детей. Родители и опекуны контролируют использование Minecraft и модов несовершеннолетними.

8. Изменения Политики

8.1. Разработчик может обновлять эту Политику. Актуальная версия всегда доступна на этой странице.

8.2. Существенные изменения рекомендуется отслеживать по дате редакции в шапке сайта. Продолжение использования Продукта после обновления Политики означает принятие новой редакции в части, применимой к Продукту.

9.1. Политика является дополнением к Условиям использования Life Visuals. В случае противоречия по вопросам обработки данных приоритет имеет более специальная норма Политики.

9.2. Если какое-либо положение Политики признано недействительным, остальные положения сохраняют силу.

9.3. Настоящая Политика не заменяет политики Mojang / Microsoft, правил отдельных серверов и условий GitHub / Discord.
